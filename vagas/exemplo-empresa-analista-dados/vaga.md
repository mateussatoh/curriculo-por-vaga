# Analista de Dados Pleno, Empresa Exemplo (vaga fictícia)

## Descrição (colada literalmente)

A Empresa Exemplo, varejista com 300 lojas, busca Analista de Dados Pleno para o time
de Inteligência Comercial. Modelo híbrido em Belo Horizonte.

**Responsabilidades**
- Construir e manter dashboards em Power BI para as áreas comerciais.
- Desenvolver pipelines de ETL e garantir a qualidade dos dados.
- Apoiar a tomada de decisão com análises ad hoc e storytelling com dados.
- Atuar junto a stakeholders de negócio na definição de KPIs.

**Requisitos**
- Experiência sólida com SQL.
- Python para análise de dados (pandas).
- Power BI e DAX.
- Conhecimento em modelagem dimensional.
- Experiência com Azure (Data Factory).

**Diferenciais**
- Databricks.
- Experiência no varejo.
- Testes A/B.
